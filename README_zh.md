# LeviSchematic

[English](README.md)

> **声明：本项目几乎所有的功能内容与 UI 设计都来自 Java 版投影模组 [Litematica](https://github.com/maruohon/litematica)（作者 masa）。** LeviSchematic 只是把这些功能移植到基岩版并适配 LeviLamina，菜单布局、按钮功能、信息 HUD、材料列表和文件元数据等均以 Litematica 为蓝本。感谢 Litematica 与 MaLiLib 的作者和贡献者。

LeviSchematic 是一个 Minecraft 基岩版客户端投影 mod，基于 LeviLamina 客户端 SDK，参考 Litematica 的使用方式。它可以把 `.levischematic`、`.litematic` 和 `.mcstructure` 文件以半透明投影的形式放进世界，在生存或创造模式下辅助建造，对照投影校验实际建筑，并把世界中的区域保存为 `.levischematic`（默认）、`.litematic` 或 `.mcstructure`。

## 运行环境

- Windows x64，Minecraft 基岩版客户端 1.26.60
- LeviLamina Client 26.60.4
- 将整个 `LeviSchematic` 目录（包含 `assets/ui`）安装到 `mods` 目录

## 功能

### 投影

- 以半透明幽灵方块显示 `.levischematic`、`.litematic` 或 `.mcstructure` 结构，可同时存在多个放置
- 结构在后台加载并逐步显示，大型结构不会卡住游戏
- 方块实体（箱子、告示牌等）和普通实体与方块一同投影
- 每个放置可设置：名称、锁定、启用/停用、显示/隐藏、原点、平移、旋转（90°/180°）、镜像（X/Z）、重置
- 支持多区域放置（每个区域独立变换）和重复网格（按轴设置次数与间距）
- 分层渲染：全部 / 单层 / 范围 / 以下 / 以上，可选 X、Y、Z 轴，并可跟随玩家
- 可配置投影颜色、染色强度、透明度、渲染距离和视锥裁剪

### 校验

- 将每个投影方块与实际世界比对，可校验完整范围或仅当前渲染层
- 正确的方块自动隐藏；缺失、方块类型错误、方块状态错误和多余方块分别以不同颜色标示
- 报告页显示各类数量、差异分组（预期 → 实际），可按类别切换高亮、忽略分组
- 未加载区块中的位置保持“未知”，不会算作正确

### 生存辅助

- 材料列表：统计当前放置、未加载的原理图文件（只读取不加载）或世界中选区内的方块；可排序表头、隐藏已有、倍率、忽略条目、物品图标，导出文本/CSV/JSON；液体按桶计算（含含水方块的水）
- 投影取物：中键点击投影方块，把对应物品放到手上，可配置允许替换的快捷栏槽位
- 方块信息：按住按键查看准星处的预期方块与实际方块
- 辅助放置（Easy Place）：在瞄准位置放置状态正确的预期方块（默认关闭；游戏无法还原的状态会跳过）
- 放置限制：在投影附近阻止与投影不符的放置（预期为空气、超出渲染层或方块不对）
- 材料 HUD 与校验 HUD

### 选区与保存

- 简单模式（单个选框）与普通模式（多个命名区域）
- 可用工具设置角点、手动编辑坐标、调整大小、自动 Grow 到周围方块、自动原点，或从已有放置创建选区
- 将选区保存为新的 `.levischematic`（默认，不写扩展名时使用）、`.litematic` 或 `.mcstructure`（可包含实体）；保存分多个 tick 逐步进行，覆盖已有文件需要确认
- `.levischematic` 是单个文件，保留全部子区域以及与 Litematica 对齐的元数据（名称、作者、时间、区域数、方块数、尺寸），原理图浏览器无需解包即可显示详情；`.litematic` 同样保留子区域；多区域选区保存为 `.mcstructure` 时会先确认，再合并为单个结构

### 编辑投影

- 在世界中直接编辑已加载的结构：删除投影方块、采样方块状态、放置采样的状态
- 匹配范围：单块、同状态、同类型、连续行
- 编辑作用于共享资源；可保存、重新加载，或“另存为”让当前放置改用新文件

### 创造世界工具

仅在创造模式下可用：

- 粘贴、网格粘贴当前放置到世界，以及填充、替换、删除、复制、移动
- 每个操作先预检，确认后再开始；可暂停、继续或取消
- 范围：全部有效区域或当前渲染层；替换策略：全部位置、仅目标为空气、仅结构非空气
- 移动操作在目标校验通过后才清除源区域

### 建筑项目与告示牌

- 建筑项目保存世界选区的不可变版本，带名称、说明和工作进度；任意版本都可以恢复为选区或作为投影加载
- 复制投影中告示牌的正面或背面文字，粘贴到下一个正常打开的告示牌

### 会话

- 放置、选区和分层设置按世界/服务器和维度分别保存
- 重新进入时，需在“会话恢复”页面确认后才会恢复

## 游戏内操作

所有快捷键都可以在“按键绑定”页面修改。默认按键：

| 按键 | 作用 |
|---|---|
| `M`（按下后松开） | 主菜单 |
| `M` + `C` | 配置菜单 |
| `M` + `P` | 放置列表 |
| `M` + `S` | 选区编辑器 |
| `M` + `L` | 材料清单 |
| `M` + `V` | 校验器 |
| `M` + `T` | 开关工具 |
| `Ctrl` + `Alt` + `S` | 保存选区 |
| 小键盘 `-` | 当前放置配置 |
| 小键盘 `*` | 选区编辑器 |
| `PageUp` / `PageDown` | 当前渲染层上移 / 下移 |
| `M` + `PageUp` / `PageDown` | 下一个 / 上一个分层模式 |
| 中键 | 投影取物（未手持工具时） |
| `M` + 中键 | 开关投影取物 |
| 按住 `I` | 显示预期/实际方块信息 |
| 右键 | 辅助放置（启用时） |

执行创造操作、创造工具、建筑项目、告示牌复制/粘贴、设为玩家所在层、辅助放置开关、放置限制开关默认没有按键，需要时可自行绑定。

### 工具

主手持工具物品（默认木棍，可配置）时可使用：

| 操作 | 作用 |
|---|---|
| `Ctrl` + 滚轮 | 切换工具模式：选区 → 放置 → 编辑（创造模式下还有粘贴、网格粘贴、填充、替换、删除、复制、移动） |
| `Ctrl` + `M` | 切换子模式：选区中为角点/扩展，编辑中为匹配范围，粘贴中为替换策略 |
| 中键 | 选择准星指向的元素：选区角点、选框或区域，或某个放置 |
| `Alt` + 滚轮 | 沿视线方向将选中元素微调一格 |

各模式下的鼠标操作：

- **选区 / 填充 / 替换 / 删除 / 复制 / 移动**：左键设置角点 1，右键设置角点 2；潜行时改为点击面外侧的方块
- **放置 / 粘贴**：点击方块，将当前放置的原点移到该处
- **编辑**：左键删除投影方块，中键采样其状态，右键放置采样的状态
- **创造工具**：中键采样准星处的目标方块

手持工具时，屏幕上的信息面板会显示工具模式、当前文件，以及选区角点或放置的原点、尺寸和变换。

## 菜单

菜单按 Litematica 的界面重建。主菜单（`M`）可以进入所有页面，标题栏以面包屑显示当前位置（`LeviSchematic vX 主菜单 => … => …`）。滚轮浏览，点击执行；悬停在按钮上会显示说明；循环按钮左键下一项、右键上一项；`±` 按钮可配合 `Shift`、`Ctrl`、`Alt` 改变步长；`Esc` 先取消当前输入或确认，再返回上一级页面。

| 页面 | 可进行的操作 |
|---|---|
| 主菜单 | 左列：放置列表、已加载原理图、加载原理图、区域编辑器、选区浏览器、选区模式；右列：配置菜单、原理图管理器、任务管理器、建筑项目；下方为本模组附加功能（编辑投影、世界操作、告示牌、会话恢复）；底部为工具模式与工具开关 |
| 加载原理图 | 目录导航（根目录、上一级、新建文件夹、在系统中打开）与搜索；右侧信息面板显示名称、作者、创建/修改时间、区域数、方块数/体积、尺寸；“创建放置实例”复选框（取消则只加载到内存，`Shift` 加载为停用）；材料列表、重命名原理图、重命名文件 |
| 原理图管理器 | 重命名原理图、更改作者；格式转换（`.levischematic` / `.litematic` / `.mcstructure`）；重命名、复制、删除文件 |
| 已加载原理图 | 创建放置（`Shift` 为停用）、保存到文件 / 另存为、重新加载、卸载 |
| 放置列表 | 每行：名称（启用绿色 / 停用红色）、锁定图标、配置、启用、移除（已锁定需 `Shift`） |
| 放置配置 | 名称与重命名；子区域列表（配置、启用、全部开启/关闭）；启用、渲染、锁定、包围盒、忽略实体；原点 XYZ（输入、`±`、轴锁定）、移动到玩家、旋转、镜像、重置子区域；页脚进入材料列表、校验器、重复网格 |
| 选区浏览器 | 选区文件 `area_selections/*.json`：新建、从放置创建、取消选择；每行配置、复制、重命名、删除 |
| 区域编辑器 | 选取模式、角点模式、手动原点；选区 / 子区域名称；角点与原点的 XYZ 输入、`±`、移动到玩家；保存原理图、分析区域；子区域列表；自动扩展、扩展/收缩、清空 |
| 保存原理图 | 文件名（扩展名决定格式，不写时为 `.levischematic`）、包含实体、保存新文件 / 覆盖、进度与取消 |
| 材料列表 | 刷新、列表类型（全部 / 渲染层）、隐藏已有、HUD 显示、倍率；表头排序；悬停显示 `N = a × 64 + b = c 潜影盒`；忽略、清空缓存、导出文本/CSV/JSON |
| 校验器 | 选择放置、开始（完整范围或渲染层）、停止、重置、报告、高亮和忽略分组 |
| 编辑投影 | 启用编辑模式、匹配范围、右键邻接添加、写入方块、保存/取消编辑 |
| 创造世界操作 | 操作类型、范围、替换策略、采样、复制/移动偏移、预检、开始、暂停、继续、取消 |
| 建筑项目 | 创建项目、保存版本、切换版本、恢复选区、粘贴版本 |
| 告示牌文本 | 复制正面/背面，粘贴到下一个打开的告示牌 |
| 任务管理器 | 集中查看加载、保存、世界操作和项目任务 |
| 会话恢复 | 恢复当前维度保存的会话，或保留当前状态 |
| 配置菜单 | 标签页：全部 / 通用 / 信息HUD / 视效 / 颜色 / 快捷键 / 渲染层；每项带说明与重置按钮 |

### 配置项

- 可见性：渲染距离、视锥裁剪
- 投影：颜色与染色强度、透明度
- 校验：缺失、类型错误、状态错误、多余方块的标示颜色，始终显示缺失/多余标示，轮廓外扩距离
- 选区面颜色、工具物品、HUD 开关
- 生存辅助选项与性能预算
- 颜色按 `#AARRGGBB` 填写（`AA` 为不透明度），旁边的色块显示当前颜色

### 快捷键

“配置菜单 → 快捷键”中，点击绑定按钮后按住新的按键或组合键，松开即保存，`Esc` 清除绑定；与默认不同的绑定显示为金色。绑定右侧的设置图标左键打开高级设置、右键恢复默认：触发时机（按下 / 松开 / 两者）、生效场景（游戏中 / 界面中 / 任意）、允许空快捷键、允许额外按键、按键顺序敏感、独占触发、取消原版触发。

### 信息 HUD

手持工具时，屏幕左下角按 Litematica 的样式显示当前工具模式的信息：选区模式下为选区名称、角点模式、子区域与两个角点坐标；放置相关模式下为当前放置、原点、尺寸、子区域数量与已修改的子区域；创造工具模式下还会显示替换方式等。各段文字分色显示，每行带半透明背景，同时显示渲染层设置。

### HUD 布局

“配置菜单 → 编辑 HUD 布局”可以调整四个 HUD 面板（投影信息、目标方块、材料、校验）：拖动面板位置，用滑块或数字把大小设为 50%～200%，也可以单独或全部重置。编辑时未激活的面板会显示示例内容，离开页面时自动保存。

## 投影文件格式

| 扩展名 | 加载 | 保存 |
|---|---|---|
| `.levischematic` | 支持，多区域 | 默认格式（不写扩展名时使用） |
| `.litematic` | 支持，多区域 | 支持，多区域 |
| `.mcstructure` | 支持，单个结构 | 支持；多区域选区会先确认，再合并为一个结构（空隙为结构空位，重叠处后面的区域覆盖前面的区域） |

`.levischematic` 是本模组的单文件格式，取代以前“每个区域一个 `.mcstructure` + `.schemset.json` 清单”的多文件保存方式：

- 文件开头是魔数 `LVSCHEM`、容器版本和一段**未压缩**的 JSON 头，之后依次是各区域数据。
- JSON 头中的 `metadata` 与 Litematica 的元数据对应：名称、作者、说明、创建/修改时间、区域数、方块数、总体积、外包尺寸；`regions` 记录每个子区域的 id、名称、相对偏移和尺寸。
- 每个区域是原版小端 NBT 的 mcstructure，使用 gzip 压缩，并带有原始长度与 CRC32 校验，读取时任何不一致都按损坏文件报错。
- 原理图浏览器只读文件头即可显示详情，无需解压区域数据；在原理图管理器中修改名称或作者只改写文件头。
- 写入为原子操作，取消或失败不会留下半个文件。

详细字节布局见 `docs/levischematic文件格式说明.md`。

## 语言

界面、HUD、聊天提示和命令输出都跟随游戏语言，内置英文和简体中文。所有文本位于 `assets/lang/<语言代码>.json`（安装到 `<mod>/assets/lang`）；新增语言时复制 `en_US.json` 为游戏语言代码（例如 `ja_JP.json`）并翻译其中的值。放在 `<配置目录>/lang/` 的同名文件可以覆盖单个键（旧版本自动生成的 `<配置目录>/i18n/ui/` 不再读取）。

## 构建

```powershell
xmake f -a x64 -m release -p windows --target_type=client
xmake
```

打包好的 mod 位于 `bin/LeviSchematic`。
